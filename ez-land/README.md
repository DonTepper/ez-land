# EZ-Land

**EZ-Land** is a 3D land parcel editor and visualization tool built with Three.js.

## Features
- Draw, edit, and delete land parcels
- Import/export GeoJSON with elevation
- Dark-themed UI with sidebar tools
- GitHub Pages deploy-ready

## Setup
```bash
npm install
npm run dev
```

## Deploy to GitHub Pages
```bash
npm run deploy
```

View live: [https://DonTepper.github.io/ez-land/](https://DonTepper.github.io/ez-land/)
